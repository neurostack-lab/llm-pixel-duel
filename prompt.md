# Задание и параметры

Обе модели получили одно и то же сообщение: один запрос, без системного промпта, без доработок и повторных попыток. В репозиторий попал код из блока ```` ```html ```` в ответе.

## Текст задания (дословно)

`````text
Сделай одну HTML-страницу с маленькой пиксельной игрой в ретро-стиле 8-бит. Весь код — в одном файле, без внешних библиотек, шрифтов и картинок: всё рисуй на <canvas>.

Игра: платформер. Персонаж бежит по уровню, прыгает через ямы и врагов, собирает монеты. В углу — счёт и жизни, пиксельный шрифт нарисуй сам. Фон с параллаксом (небо, горы, облака), анимация спрайтов (бег, прыжок), частицы при сборе монеты. Звук не нужен.

Обязательно:
- режим демо: сразу после загрузки персонаж играет сам (автопилот без ввода игрока) не меньше 30 секунд, не застревает и не погибает в первые секунды; стрелки и пробел перехватывают управление;
- canvas 960×540, логическое разрешение 240×135 с масштабом ×4, image-rendering: pixelated;
- уровень длиннее экрана, камера следует за персонажем.

Верни только код в одном блоке ```html```.
`````
